# World Enhancer — Learn the Tools, Enhance the World

職業編第一弾。3D素人が、HD-2D lite を HD-2D フル版にすることに奮闘し、学んで、身につけて、「World Enhancer」になるまでを経験するデスクトップRPG。

- 仕様書： app-concepts goal files の `world-enhancer-spec-2026-11-27.md`（正本）
- 公開用リポジトリ： ukos/nono-world-enhancer-playground（https://ukos.github.io/nono-world-enhancer-playground/ ）
- 本リポジトリは開発用（ソース）。公開物は公開用リポジトリへ置く

## 遊び方

単一の `index.html` をブラウザで開くだけで動く（外部ライブラリなし）。セーブは localStorage。

## v0.8

追加エピソード2本が入り、全30クエストになった。素材はユーザーの実機スクリーンショット（HD-2D lite と フル版到達イメージの比較画像、初めての Unity 初期状態）から切り出した3点。
- 追加1「はじめてのゆにてぃ」： 記録写真（Unity 初期状態）の上に、写っている素材を置き直して最初のシーンを再現する（新タイプ photoscene）
- 追加2「到達イメージ」： lite の画面を、右上に表示した到達イメージ（フル版最終形）に光と色で寄せる（adjust の見本差し替え版）。最終メールも差し替え

## v0.7

第2部（仕事21〜28）が追加され、全28クエストになった。舞台は趣味の個人制作。
- 呼称システム： 全スキルの経験値合計で称号が上がる（みならい → コーダー → アプリデザイナー → レンダラー → デザイナー → モデラー → ワールドエンハンサー）。ステータスバーに表示し、昇格は納品結果でも知らせる
- AIエージェント： 仕事22で新アイテムとして登場。新コマンド「まかせる」で星の下書きを描くが、ずれた3点を人が直す（新タイプ aifix）。仕事24では先積み（間違い混じり）、仕事26では正しい結線を1組、先行してくれる
- ライバル： 仕事23で Gemini 4 Carbon と Godot 4.7 を掲げて挑戦してくる。メールはクエストごとに差出人を持てるようになった（先輩／自分へのメモ／ライバル）
- 仕事25は HD-2D の箱庭の夕景、仕事27は旗2つの巡回路、仕事28が第2部の卒業制作で、最終メールが真のエンディングになった
